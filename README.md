# DSA-Proyecto
Repo para el proyecto

Proyecto Java 17 con Maven, sin dependencias.

- `src/main/java`: código Java.
- `src/main/resources`: recursos de la aplicación.
- `src/test/java`: pruebas.
- `src/test/resources`: recursos de las pruebas.

Compilar con `mvn compile` (requiere JDK 17 o superior y Maven).

En IntelliJ IDEA, abrir el archivo `pom.xml` como proyecto Maven.
